# Evidence

This folder is for the raw evidence of the project: photos of price tags, form exports, recordings, interview notes, sketches, the storyboard and the test results.

Git ignores everything in this folder except this note. The photos and the notes show vendors and students, and the course brief says that we never publish the names of vendors and that we delete identifying details before we hand in. So my group keeps the evidence in the shared team folder, and it goes into the final ZIP from there.

Each record carries the name of the collector, the date and the time, and every photo keeps its original timestamp.
